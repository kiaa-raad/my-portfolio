## Overview

MacBook Pro Wallpaper is a small 3D experiment that started with a request from a friend who wanted alternative color options for the MacBook Pro wallpaper. Since the original design was only available in black, they asked me to create different color variations for them.

## Contribution

I recreated the MacBook Pro wallpaper in Blender, building the composition as a 3D scene and experimenting with different color variations while keeping the visual character of the original design.

The project became a small exercise in 3D modeling, materials, lighting, and color exploration, using Blender to reinterpret the original wallpaper and create alternative versions.
